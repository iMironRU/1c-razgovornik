# § 5.1. Процедура и функция — почему их две

В Python, JavaScript и C# подпрограмма одна. Возвращает она что-нибудь или нет — дело её внутреннего устройства, а не объявления: `def`, `function`, тип возврата.

В 1С это два разных ключевых слова, и выбор делается заранее.

```bsl,песочница
// Функция обязана вернуть значение
Функция СуммаСНалогом(Сумма, Ставка)
    Возврат Сумма + Сумма * Ставка / 100;
КонецФункции

// Процедура не возвращает ничего
Процедура СообщитьИтог(Сумма)
    Сообщить("Итого: " + Сумма);
КонецПроцедуры

Итог = СуммаСНалогом(1000, 20);
СообщитьИтог(Итог);        // 1200
```

Разница не косметическая. Функцию можно поставить справа от `=` и внутрь выражения; процедуру — нельзя, её вызов это отдельный оператор. Попытка написать `Х = СообщитьИтог(100)` не пройдёт компиляцию.

| | 1С | Python | JavaScript | C# |
|---|---|---|---|---|
| объявление | `Функция` / `Процедура` | `def` | `function` | тип возврата или `void` |
| решение о возврате | при объявлении | в теле | в теле | при объявлении |
| выход раньше времени | `Возврат;` (только в процедуре) | `return` | `return` | `return` |

Ближе всего C#: там `void` тоже объявляется заранее. Но `void` в C# — служебный маркер отсутствия возврата, а в 1С процедура и функция — разные синтаксические конструкции с разными словами закрытия: `КонецПроцедуры` и `КонецФункции`.

> `Возврат` работает в обоих: в функции — с выражением, в процедуре — сам по себе, как досрочный выход. Функция, дошедшая до `КонецФункции` без `Возврат`, отдаёт `Неопределено`.

```bsl,песочница
Функция НайтиСкидку(Клиент)
    Если Клиент = "" Тогда
        Возврат 0;                  // ранний выход со значением
    КонецЕсли;
    Возврат 10;
КонецФункции

Процедура Проверить(Значение)
    Если Значение = Неопределено Тогда
        Возврат;                    // просто выйти
    КонецЕсли;
    Сообщить("Проверено: " + Значение);
КонецПроцедуры

Сообщить(НайтиСкидку("Иванов"));    // 10
Проверить(Неопределено);            // ничего не выведет
Проверить("Ручка");                 // Проверено: Ручка
```

**Ловушки при переходе:**

*Из Python в 1С.* Привычка «напишу `def`, а там разберусь» не сработает: решение принимается в первой строке. Если по ходу выяснилось, что значение всё-таки нужно вернуть, придётся менять и слово, и закрывающую строку.

*Из JavaScript в 1С.* Функция здесь не значение. Её нельзя присвоить переменной, передать аргументом и вернуть из другой функции — об этом отдельно дальше в главе.

*Из 1С наружу.* Разделение исчезает: в Python и JavaScript всё одно, и функция без `return` просто отдаёт `None` или `undefined`. Отдельного слова для «процедуры» искать не нужно, его нет.
