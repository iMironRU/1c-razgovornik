# § 5.3. Значения по умолчанию и пропуск параметров

Значение по умолчанию пишется в объявлении, как везде:

```bsl,песочница
Функция Приветствие(Имя, Обращение = "Уважаемый")
    Возврат Обращение + " " + Имя;
КонецФункции

Сообщить(Приветствие("Иванов"));                 // Уважаемый Иванов
Сообщить(Приветствие("Иванова", "Уважаемая"));   // Уважаемая Иванова
```

Дальше начинаются отличия, и их три.

**Первое: значением по умолчанию ставят константу.** Число, строку, булево, дату, `Неопределено`. Вычисляемого выражения там не бывает — ни вызова функции, ни `Новый Массив`.

Питонисту это скорее подарок: знаменитая ловушка с изменяемым значением по умолчанию, `def f(x=[])`, здесь невозможна в принципе.

**Второе: параметр можно пропустить посередине.** Пустое место между запятыми означает «бери значение по умолчанию»:

```bsl,песочница
Функция Собрать(Первый = "а", Второй = "б", Третий = "в")
    Возврат Первый + Второй + Третий;
КонецФункции

Сообщить(Собрать("Х", , "Я"));     // ХбЯ — второй пропущен
```

**Третье: именованных аргументов нет.** Написать `Собрать(Третий = "Я")` нельзя — только позиционно, только пустым местом.

| | 1С | Python | JavaScript | C# |
|---|---|---|---|---|
| значение по умолчанию | константа | любое выражение | любое выражение | константа |
| пропуск в середине | `Ф(а, , в)` | по имени | `undefined` | по имени |
| именованные аргументы | нет | `f(x=1)` | нет | `M(x: 1)` |
| переменное число | нет | `*args` | `...rest` | `params` |

> Переменного числа параметров в 1С нет вовсе. Когда аргументов много и часть из них необязательна, в живом коде передают одну **структуру** — она заменяет и именованные аргументы, и `**kwargs`.

```bsl,песочница
Функция Оформить(Параметры)
    Скидка = ?(Параметры.Свойство("Скидка"), Параметры.Скидка, 0);
    Возврат "Скидка: " + Скидка;
КонецФункции

П = Новый Структура;
П.Вставить("Скидка", 15);
Сообщить(Оформить(П));             // Скидка: 15
```

Приём распространён настолько, что в чужом коде процедура с единственным параметром `Параметры` встречается постоянно — и это не лень автора, а обход отсутствующей возможности языка.

**Ловушки при переходе:**

*Из Python в 1С.* Именованных аргументов нет — при вызове чужой процедуры с семью параметрами придётся считать запятые. И наоборот: ловушка с изменяемым значением по умолчанию здесь не работает, потому что изменяемое значение туда не поставить.

*Из C# в 1С.* Перегрузки нет, а значит трюк «две сигнатуры для двух случаев» не пройдёт: остаются значения по умолчанию и структура.

*Из 1С наружу.* Пустое место между запятыми — конструкция 1С. В Python пропускают по имени, в JavaScript передают `undefined` явно.
