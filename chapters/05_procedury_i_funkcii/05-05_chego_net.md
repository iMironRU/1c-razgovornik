# § 5.5. Чего нет: перегрузка, лямбды, замыкания

Это самый короткий способ сэкономить вам полдня: перечислить приёмы, которые вы будете искать и не найдёте.

**Перегрузки нет.** Двух методов с одним именем в модуле не бывает — компилятор не даст. Разные случаи разводят либо значениями по умолчанию, либо разными именами: `ПрочитатьПоСсылке`, `ПрочитатьПоКоду`.

**Функция не значение.** Её нельзя присвоить переменной, передать параметром, вернуть из другой функции, положить в массив. Всё, что в Python и JavaScript строится на функциях высшего порядка, здесь строится иначе.

**Лямбд и замыканий нет.** Ни `lambda`, ни стрелочных функций, ни захвата переменных из окружения.

**Из этого следует отсутствие целого пласта приёмов:**

| приём | Python | JavaScript | в 1С |
|---|---|---|---|
| функция как аргумент | `map(f, xs)` | `xs.map(f)` | явный цикл |
| фильтрация | `filter` | `.filter()` | явный цикл |
| свёртка | `reduce` | `.reduce()` | явный цикл с накопителем |
| сортировка по ключу | `key=` | `.sort(cmp)` | `Сортировать("Колонка Убыв")` у таблицы |
| колбэк | функция | функция | `ОписаниеОповещения` |
| декоратор | `@` | обёртка | нет |
| частичное применение | `partial` | замыкание | нет |

Единственное, что отдалённо заменяет передачу функции, — **вызов по имени**: имя метода передаётся строкой, а платформа его находит.

```bsl,платформа
// Отложенный вызов: имя обработчика — строка
Оповещение = Новый ОписаниеОповещения("ПослеЗакрытия", ЭтотОбъект);
ПоказатьВопрос(Оповещение, "Продолжить?", РежимДиалогаВопрос.ДаНет);
```

Это не функция как значение: передаётся не сам метод, а его имя и место, где его искать. Компилятор такую строку не проверяет — опечатка в имени превратится в ошибку времени выполнения.

> Отсутствие функций-значений — не упущение, а следствие возраста и назначения языка. Он проектировался как язык прикладной автоматизации, где важнее читаемость чужого кода бухгалтером-программистом, чем выразительность.

**Ловушки при переходе:**

*Из Python в 1С.* Первое, чего будет не хватать, — `map` и `filter`. Пишите цикл и не ищите обходного пути: его нет, и любая попытка изобрести его через `Выполнить()` сделает код хуже.

*Из JavaScript в 1С.* Колбэк существует, но выглядит как строка с именем. Проверка опечатки — только запуском.

*Из C# в 1С.* Ни LINQ, ни делегатов, ни перегрузки. Ближайшее к LINQ по духу — язык запросов, но он про данные в базе, а не про коллекции в памяти.

*Из 1С наружу.* Привычка писать цикл на всё подряд будет читаться как неумение: в Python и JavaScript тот же перебор ожидают увидеть одной строкой.
