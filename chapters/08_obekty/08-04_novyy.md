# § 8.4. Что на самом деле делает `Новый`

Слово выглядит как `new` из C# и JavaScript, но работает иначе, и разница проступает сразу, как только приглядеться.

```bsl,песочница
// Так — можно: это встроенные типы платформы
Список  = Новый Массив;
Данные  = Новый Структура("Имя, Код", "Ручка", 42);
Таблица = Новый ТаблицаЗначений;
```

А вот так — нельзя, и не потому что забыли:

```bsl,набросок
Товар = Новый Номенклатура;          // ошибка: такого типа нет
Клиент = Новый Клиент;               // ошибка: своих классов нет
```

**`Новый` создаёт только типы, которые предоставила платформа.** Список закрыт: коллекции, запросы, файлы, шрифты, цвета и прочая утварь. Прикладные объекты — справочники, документы — через `Новый` не создаются вовсе; для них есть менеджер:

```bsl,платформа
Товар = Справочники.Номенклатура.СоздатьЭлемент();
Док   = Документы.Реализация.СоздатьДокумент();
```

| | 1С | Python | JavaScript | C# |
|---|---|---|---|---|
| ключевое слово | `Новый` | вызов класса | `new` | `new` |
| для своих типов | нельзя | да | да | да |
| для прикладных объектов | через менеджер | — | — | — |
| конструктор с параметрами | у части типов | `__init__` | `constructor` | конструкторы |

Параметры `Новый` принимает не у всех типов и у разных — по-разному. `Новый Массив(3, 4)` берёт размерности, `Новый Структура("Ключи", значения…)` — строку ключей и значения. Своего конструктора вы не напишете: писать нечего, класса-то нет.

> Проверка, которая экономит время: если в чужом коде видите `Новый ЧтоТо`, это точно тип платформы. Прикладной объект так не создаётся, и путать эти два способа — распространённая ошибка новичка.

**Ловушки при переходе:**

*Из C# в 1С.* `new` работает только с закрытым списком типов. Своего конструктора нет и быть не может.

*Из JavaScript в 1С.* Объектных литералов нет: `{}` превращается в `Новый Структура`, и заполняется он через `Вставить`, а не через точку.

*Из Python в 1С.* Вызов класса как конструктора не переносится: имя типа здесь не значение и в переменную его не положишь.

*Из 1С наружу.* Разделение «`Новый` для платформенного, менеджер для прикладного» исчезнет — снаружи всё создаётся одинаково.
