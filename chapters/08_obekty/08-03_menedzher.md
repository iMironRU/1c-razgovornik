# § 8.3. Менеджер: статика без класса

У каждого объекта конфигурации есть **менеджер** — то место, куда в других языках кладут статические методы.

```bsl,платформа
// Через менеджер — то, что относится ко всем товарам сразу
Ссылка = Справочники.Номенклатура.НайтиПоКоду("00042");
Новый   = Справочники.Номенклатура.СоздатьЭлемент();
Выборка = Справочники.Номенклатура.Выбрать();

// Через объект — то, что относится к одному
Товар = Ссылка.ПолучитьОбъект();
Товар.Записать();
```

Разделение то же, что между `static` и обычным методом: менеджер знает про вид объекта в целом, объект — про конкретный экземпляр.

| | 1С | Python | JavaScript | C# |
|---|---|---|---|---|
| где живёт | модуль менеджера | `@staticmethod`, `@classmethod` | `static` в классе | `static` в классе |
| как вызывается | `Справочники.Имя.Метод()` | `Класс.метод()` | `Класс.метод()` | `Класс.Метод()` |
| доступен ли экземпляр | нет | нет | нет | нет |

Своё туда добавлять можно: в модуле менеджера пишутся экспортные функции, и вызываются они так же, как встроенные.

```bsl,платформа
// В модуле менеджера справочника «Номенклатура»
Функция НайтиПоАртикулу(Артикул) Экспорт
    // …
КонецФункции

// Где угодно в конфигурации
Товар = Справочники.Номенклатура.НайтиПоАртикулу("A-100");
```

> Здесь и проходит граница между модулем объекта и модулем менеджера, и она ровно та же, что между обычным и статическим методом. Вопрос при чтении чужого кода один: этот метод про **один** экземпляр или про **все**?

**Ловушки при переходе:**

*Из C# в 1С.* Модуль менеджера — это статический класс-компаньон, и разложены они по разным файлам. Привычка держать статику рядом с обычными методами не сработает: это два разных модуля.

*Из Python в 1С.* `@classmethod` с его `cls` заменить нечем: менеджер не получает тип параметром, он и есть точка входа.

*Из JavaScript в 1С.* Ближайшее — статические методы класса. Разница в том, что здесь они физически в другом файле.

*Из 1С наружу.* Раскладывание по двум модулям пропадёт: снаружи статика и экземплярные методы живут в одном классе, и это поначалу выглядит беспорядком.
