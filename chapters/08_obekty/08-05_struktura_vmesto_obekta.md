# § 8.5. Чем заменяют объект на ходу

Привычка собрать объект прямо в выражении есть у всех троих: `{"имя": "Иван"}` в Python, `{ имя: "Иван" }` в JavaScript, анонимный тип в C#. Здесь для этого есть **Структура**, и она ближе, чем кажется.

```bsl,песочница
// Собрали на ходу
Клиент = Новый Структура("Имя, Город", "Иван", "Москва");
Сообщить(Клиент.Имя);                 // обращение через точку

// Добавили поле позже
Клиент.Вставить("Скидка", 10);

// Проверили наличие — ключи не гарантированы
Если Клиент.Свойство("Телефон") Тогда
    Сообщить(Клиент.Телефон);
КонецЕсли;
```

Обращение через точку роднит её с объектом; отсутствие методов — отличает. Поведения в структуру не положишь: функций как значений в языке нет. Единственное, что туда ложится похожего, — `ОписаниеОповещения`, то есть имя процедуры и место, где её искать.

Рядом живёт **Соответствие** — это словарь в чистом виде:

```bsl,песочница
Курсы = Новый Соответствие;
Курсы.Вставить("USD", 92.5);
Курсы.Вставить("EUR", 99.1);

Сообщить(Курсы.Получить("USD"));   // 92.5, по ключу
```

| | Структура | Соответствие | Python | JavaScript |
|---|---|---|---|---|
| ключи | только имена-идентификаторы | любые значения | любые хешируемые | строки и символы |
| обращение | через точку | `Получить()` | `d["k"]` | `o.k` и `o["k"]` |
| ближайший аналог | анонимный объект | `dict` | — | `Map` |

Разделение проходит по ключу. Ключ структуры — имя, оно должно годиться в идентификаторы: без пробелов, не с цифры. Ключ соответствия — что угодно, хоть ссылка на справочник, хоть массив.

> Правило, по которому выбирают: если ключи известны при написании кода — структура; если приходят из данных — соответствие. Питонисту стоит запомнить, что здесь `dict` расщепился надвое, и первая половина обращается через точку.

**Ловушки при переходе:**

*Из Python в 1С.* `dict` с произвольными ключами — это Соответствие, а не Структура. И `.get(key, default)` с умолчанием заменяется на `Получить()`, который вернёт `Неопределено`.

*Из JavaScript в 1С.* Объектный литерал разложился на два типа. Свойства структуры перечисляются строкой при создании, а не парами.

*Из C# в 1С.* Анонимный тип — это структура, но без проверки типов при компиляции: опечатка в имени поля станет ошибкой выполнения.

*Из 1С наружу.* Различие «структура или соответствие» исчезнет: снаружи один словарь на оба случая, а через точку он обращаться не умеет.
